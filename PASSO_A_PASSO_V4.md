# ADS & ADS — V4

1. Extraia o ZIP.
2. No GitHub, abra o repositório `adsandads-lp`.
3. Add file → Upload files.
4. Selecione todos os arquivos desta pasta.
5. Faça o commit: `V4 - fluxo conectado, serviços e prova social`.
6. Aguarde o Cloudflare concluir a implantação.
7. Teste primeiro a URL específica do deploy e depois `adsandads-lp.pages.dev`.
