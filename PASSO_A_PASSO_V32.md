# ADS & ADS — V3.2

## O que mudou
- Serviços foram movidos para a seção **Soluções**.
- A seção **Método** ficou dedicada apenas à forma de trabalho e ao processo.
- Os nomes dos serviços passaram a usar português como rótulo principal, preservando termos de mercado como Growth, CRM, Tracking, Analytics, CRO e Marketing Ops quando ajudam a compreensão.
- A seção **Sobre** ganhou uma faixa horizontal de clientes e projetos já atendidos.

## Publicar no GitHub
1. Extraia o ZIP.
2. Abra o repositório `adsandads-lp`.
3. Add file → Upload files.
4. Selecione todos os arquivos desta pasta.
5. Faça commit na branch de produção.
6. Sugestão de commit: `V3.2 - solucoes, metodo, clientes e SEO em portugues`.
7. Espere a implantação do Cloudflare ficar verde.
8. Teste primeiro a URL específica da implantação e depois o domínio `pages.dev`.

> A faixa de clientes usa os favicons dos domínios públicos para manter o pacote leve. Para a versão definitiva, se você tiver os arquivos oficiais das marcas, substitua pelos logos autorizados em SVG/PNG local.
