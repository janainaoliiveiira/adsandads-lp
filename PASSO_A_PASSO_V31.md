# Como publicar a V3.1 no GitHub / Cloudflare

1. Abra o repositório `adsandads-lp` no GitHub.
2. Clique em **Add file > Upload files**.
3. Abra esta pasta extraída e selecione todos os arquivos da raiz.
4. Arraste para o GitHub. Os arquivos com o mesmo nome substituirão a V3.
5. Faça o commit com a mensagem: `V3.1 - tipografia, escopo, rodape e SEO tecnico`.
6. Aguarde o Cloudflare criar uma nova implantação.
7. Teste primeiro a URL específica da implantação.
8. Depois teste `adsandads-lp.pages.dev` com Ctrl+Shift+R.
9. Quando a versão estiver aprovada, conecte `ads-ads.com.br`.
10. Somente depois do domínio final estar ativo, siga `SEO_E_INDEXACAO.md` e peça indexação no Google Search Console.

Arquivos novos importantes: `robots.txt`, `sitemap.xml`, `favicon.png`, `hero-ecosystem.webp`, `logo-symbol.webp`.
